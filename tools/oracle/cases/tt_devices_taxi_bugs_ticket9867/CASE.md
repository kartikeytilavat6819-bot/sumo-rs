# Imported TextTest case

Source: `devices/taxi/bugs/ticket9867` (SUMO 1.28.0 official TextTest suite).

Collated options (`options.sumo`, parent first):

```
--no-step-log --no-duration-log --net-file=net.net.xml -r input_routes.rou.xml --device.taxi.dispatch-period 10 --device.taxi.idle-algorithm randomCircling --tripinfo-output tripinfos.xml --tripinfo-output.write-unfinished --vehroute-output vehroutes.xml --vehroute-output.write-unfinished --stop-output stopinfos.xml -e 1000
```

`sim.args` keeps the behaviour options; net/route/additional/output files
are copied into this case and the net/route are exposed as
`ref_simple.net.xml` / `routes.rou`. TextTest-specific output files are not
imported; run_all compares tripinfo/fcd/statistics regenerated by the
official sumo via `make_sim_refs.sh`.
