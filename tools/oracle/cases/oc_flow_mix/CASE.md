# oc_flow_mix

Flows using `probability` with `end`, `number` with `period`, `probability` with `number`, and
fractional `begin`/`end`, with `departLane="best_prob"`, `departPos="free"`, `departSpeed="avg"`,
`arrivalPos="center"` and `arrivalLane="first"`. A `scale` variant uses `--scale 0.5`.
Sim: `--end 80 --seed 9`.
