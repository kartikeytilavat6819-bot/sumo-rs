# rr_veh_params

Rerouting device configured per type and per vehicle via `<param>` (no global device options):
`fastRR` (period 5), `slowRR` (period 20), vehicle `c0` overrides type `noRR` with its own
probability/period params, and `c1`/`c2` are controls with no device. Top edge `11` closed.
Refs generated with pristine C++ 1.28.0 (WSL).
