# Imported TextTest case

Source: `pedestrian_model/striping/bugs/ticket7853` (SUMO 1.28.0 official TextTest suite).

Collated options (`options.sumo`, parent first):

```
--write-license --default.departspeed 0 --default.departlane first --pedestrian.model striping --net-file net.net.xml --route-files input_routes.rou.xml --no-step-log --tripinfo-output tripinfos.xml --pedestrian.striping.mingap-to-vehicle 0 --step-length 0.1 --step-method.ballistic --default.speeddev 0 -e 60
```

`sim.args` keeps the behaviour options; net/route/additional/output files
are copied into this case and the net/route are exposed as
`ref_simple.net.xml` / `routes.rou`. TextTest-specific output files are not
imported; run_all compares tripinfo/fcd/statistics regenerated by the
official sumo via `make_sim_refs.sh`.
