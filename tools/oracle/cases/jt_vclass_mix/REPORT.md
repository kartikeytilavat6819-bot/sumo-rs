# jt_vclass_mix — mixed vehicle classes at a right-before-left junction

Right-before-left 4-arm junction with 20 vehicles cycling through four
vTypes: `passenger`, `bicycle`, `motorcycle` and `truck` (different lengths,
speeds, accelerations). Tests right-of-way and simulation with non-car
vehicle classes at a junction — all committed `jt_*` cases use default cars.

Net: C++ netconvert 1.28.0; sim refs: C++ sumo 1.28.0, `--end 200`.
