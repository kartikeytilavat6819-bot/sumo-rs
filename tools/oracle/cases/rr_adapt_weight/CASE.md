# rr_adapt_weight

Rerouting device with exponential-moving-average weight: `--device.rerouting.adaptation-weight 0.5`
and `--device.rerouting.adaptation-interval 5` (period 10, probability 1). Same parallel-edge net
and top-edge `11` closure as `rr_period`. Refs generated with pristine C++ 1.28.0 (WSL).
