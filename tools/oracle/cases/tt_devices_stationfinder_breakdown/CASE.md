Source: `devices/stationfinder/breakdown` (SUMO 1.28.0 official TextTest suite).

```
--write-license --default.speeddev 0 --default.departspeed 0 --default.departlane first --no-step-log --no-duration-log --net-file=net.net.xml -a=input_additional.add.xml -r input_routes.rou.xml --battery-output battery.xml --battery-output.precision 4 --device.stationfinder.probability 1 --chargingstations-output chargingstations.xml --tripinfo-output tripinfos.xml
```

`sim.args` keeps the behaviour options; net/route/additional/output files
are copied into this case and the net/route are exposed as
`ref_simple.net.xml` / `routes.rou`. TextTest-specific output files are not
imported; run_all compares tripinfo/fcd/statistics regenerated by the
official sumo via `make_sim_refs.sh`.
