# Imported TextTest case

Source: `tls/off_allwayStop/all_off` (SUMO 1.28.0 official TextTest suite).

Collated options (`options.sumo`, parent first):

```
--write-license --default.speeddev 0 --default.departspeed 0 --default.departlane first --no-step-log --no-duration-log --net-file=net.net.xml --routes=input_routes.rou.xml -b 0 -e 600 -a input_additional.add.xml --tls.all-off --tripinfo-output tripinfos.xml
```

`sim.args` keeps the behaviour options; net/route/additional/output files
are copied into this case and the net/route are exposed as
`ref_simple.net.xml` / `routes.rou`. TextTest-specific output files are not
imported; run_all compares tripinfo/fcd/statistics regenerated by the
official sumo via `make_sim_refs.sh`.

## FCD ref omitted
The official fcd output for this case exceeds 5 MB (artificial output added by
make_sim_refs.sh, not part of the original TextTest config). It is dropped to keep
the oracle set practical; tripinfo + statistic refs are compared instead.
