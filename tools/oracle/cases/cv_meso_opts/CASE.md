# cv_meso_opts
Meso on a TLS cross (b) feeding a priority merge (c, minor M). Base: `--meso-junction-control true`.
Variants: `limited` (--meso-junction-control.limited), `tlsflow` (--meso-tls-flow-penalty 1), `minor`
(--meso-minor-penalty 3 --meso-tls-penalty 0.5), `queue` (--meso-lane-queue + --meso-overtaking + junction control).
