```
--write-license --default.speeddev 0 --default.departspeed 0 --default.departlane first --pedestrian.model jupedsim -e 2000 --net-file net.net.xml --route-files input_routes.rou.xml --tripinfo-output tripinfos.xml --no-step-log --pedestrian.striping.dawdling 0
```

are copied into this case and the net/route are exposed as
`ref_simple.net.xml` / `routes.rou`. TextTest-specific output files are not
imported; run_all compares tripinfo/fcd/statistics regenerated by the
official sumo via `make_sim_refs.sh`.
