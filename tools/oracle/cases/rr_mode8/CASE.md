# rr_mode8

`--device.rerouting.mode 8` (bit 8 = ignore temporary permission changes / blockages from rerouters).
With top edge `11` closed by a rerouter, a device in mode 8 ignores that transient closure when
computing routes. Same parallel-edge net, probability 1, period 10. Refs generated by C++ 1.28.0 (WSL).
