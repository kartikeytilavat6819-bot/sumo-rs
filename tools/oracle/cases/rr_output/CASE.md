# rr_output

`--device.rerouting.output` writes the adapted edge weights (a `<weights>` / meandata XML) every
`--device.rerouting.adaptation-interval 5` seconds. Probability 1, period 10, top edge `11` closed.
`extra_outputs.txt` makes the harness compare `ref.rerouting.xml` exactly. Refs generated with
pristine C++ 1.28.0 (WSL).
