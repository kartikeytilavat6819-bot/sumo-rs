# Imported TextTest case

Source: `devices/taxi/bugs/ticket17168` (SUMO 1.28.0 official TextTest suite).

Collated options (`options.sumo`, parent first):

```
--no-step-log --no-duration-log --net-file=net.net.xml -r input_routes.rou.xml -a input_additional.add.xml --vehroute-output vehroutes.xml --default.departspeed 0
```

`sim.args` keeps the behaviour options; net/route/additional/output files
are copied into this case and the net/route are exposed as
`ref_simple.net.xml` / `routes.rou`. TextTest-specific output files are not
imported; run_all compares tripinfo/fcd/statistics regenerated by the
official sumo via `make_sim_refs.sh`.

## PARKED

Multi-modal person stage handling in the Rust port is not yet faithful: the person's total trip duration is roughly twice the C++ value while the walking statistics match, so the extra time accumulates in waiting/transfer stages. Re-enable when MSTransportable stage timing matches the C++.
