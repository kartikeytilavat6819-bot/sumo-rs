# jt_allway_vclass — all-way-stop junction with mixed vehicle classes

Same 4-arm allway_stop net as jt_allway_stop, but 20 vehicles cycle through passenger, bicycle,
motorcycle and truck vTypes. Tests all-way-stop ordering when approach speeds and lengths differ —
jt_allway_stop uses cars only and jt_vclass_mix uses a right_before_left junction.
