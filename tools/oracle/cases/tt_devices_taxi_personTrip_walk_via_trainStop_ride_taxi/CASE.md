# Imported TextTest case

Source: `devices/taxi/personTrip/walk_via_trainStop_ride_taxi` (SUMO 1.28.0 official TextTest suite).

Collated options (`options.sumo`, parent first):

```
--write-license --default.speeddev 0 --default.departspeed 0 --default.departlane first --no-duration-log --no-step-log --net-file=net.net.xml -a input_additional.add.xml -r input_routes.rou.xml --vehroutes=vehroutes.xml --persontrip.transfer.walk-taxi ptStops --persontrip.transfer.taxi-walk ptStops
```

`sim.args` keeps the behaviour options; net/route/additional/output files
are copied into this case and the net/route are exposed as
`ref_simple.net.xml` / `routes.rou`. TextTest-specific output files are not
imported; run_all compares tripinfo/fcd/statistics regenerated by the
official sumo via `make_sim_refs.sh`.
