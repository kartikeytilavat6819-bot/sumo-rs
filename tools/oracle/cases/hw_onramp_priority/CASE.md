# hw_onramp_priority

Three-lane highway (E0 -> E1, 25 m/s) with a one-lane on-ramp (ramp, 20 m/s) merging at
priority node n1. The ramp yields to the mainline; ramp vehicles must find a gap and change
lane after entering E1. Mainline cars start in different lanes.

Sim: `--end 200`. Net from node/edge XML via `net_ref.sh`.
